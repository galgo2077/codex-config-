# Web and documentation rules

Do not browse automatically.

Use external research only when a current fact is required behavior is version-specific upstream may have changed local documentation is insufficient or an obscure external error remains unresolved.

Prefer official primary sources and narrow queries. Read only what changes the next decision. Do not retain large documentation responses.

Use documentation tools only for uncertain library API or version behavior. Use browser tools only for actual browser interaction. Load `mcp.txt.md` when the selected capability is an MCP.

Do not claim web verification without performing it. Respect source licenses and do not copy unneeded code.
