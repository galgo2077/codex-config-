# Troubleshooting rules

Find the root cause. Do not guess or patch randomly.

Escalate in this order:

1. Read the exact error.
2. Inspect directly relevant code config logs and exit status.
3. Use relevant existing project notes.
4. Use relevant local coding or project documentation.
5. Use local library documentation.
6. Use Context7 only for a library or API uncertainty.
7. Use narrow internet research only when local information is insufficient.
8. Add an agent Ponytail or Roundtable only when still justified.

Prefer one likely hypothesis and one cheap discriminating test. Apply the smallest root-cause fix then reproduce the original failure and run targeted regression validation.
