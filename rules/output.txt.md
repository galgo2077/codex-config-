TABLE RULES

KEEP VALUES SHORT

USE ONE LINE PER FIELD

DO NOT ADD USELESS DETAIL

USE NONE WHEN FIELD DOES NOT APPLY

USE FAILED WHEN REQUIRED CHECK FAILED

WHAT WAS DONE
